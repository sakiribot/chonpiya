# กลางแอดชนม์ปิยะ คงมณี — Kanom Middleman

เว็บไซต์ Static HTML/CSS/JavaScript พร้อมคลังหลักฐาน **30 วิดีโอ** และ **29 รูปภาพ** รองรับมือถือ ค้นหา/กรองประเภทหลักฐาน และเปิดดูภาพหรือวิดีโอในหน้าต่างขยาย

## วิธีประกอบไฟล์เว็บไซต์
ไฟล์มีขนาดใหญ่เพราะรวมวิดีโอไว้ให้แล้ว จึงแบ่งเป็น 5 ZIP เพื่อดาวน์โหลดได้สะดวก:

1. ดาวน์โหลด `01-kanom-site-files.zip` และ `02` ถึง `05` ให้ครบ
2. แตกไฟล์ ZIP ทั้ง 5 ไฟล์ลงในโฟลเดอร์เดียวกัน โดยกดอนุญาตให้รวมโฟลเดอร์ `kanom-middleman-site` เดียวกัน
3. เปิด `kanom-middleman-site/index.html` ใน Chrome หรือ Edge เพื่อทดลองใช้งาน

## เผยแพร่ผ่าน GitHub Pages
1. สร้าง repository ใหม่บน GitHub
2. อัปโหลด **เนื้อหาทั้งหมดภายใน** โฟลเดอร์ `kanom-middleman-site` (ไม่ใช่ ZIP) โดยคงโครงสร้างโฟลเดอร์เดิมไว้
3. ไปที่ **Settings → Pages**
4. เลือก **Deploy from a branch**, เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
5. รอ GitHub สร้าง URL ให้

วิดีโอถูกบีบอัดให้ขนาดเล็กลงแล้ว แต่รวมกันยังมีขนาดหลายร้อย MB หากต้องการอัปโหลดทั้งหมดขึ้น GitHub ควรตรวจสอบขนาด repository และข้อจำกัดปัจจุบันก่อน หากใหญ่เกินไป ให้โฮสต์วิดีโอแยกและแก้ URL ใน `script.js`

## ความเป็นส่วนตัว — สำคัญ
ก่อนเผยแพร่สาธารณะ ให้ตรวจทุกภาพและวิดีโอว่ามีเลขบัญชีเต็ม เบอร์โทร ชื่อจริงของบุคคลอื่น QR รับเงิน เลขอ้างอิง หรือข้อมูลส่วนตัวที่ไม่ต้องการเปิดเผยหรือไม่ เว็บไซต์ GitHub Pages เป็นสาธารณะ ไม่ควรใช้เก็บหลักฐานที่ต้องจำกัดสิทธิ์เข้าถึง
